# AIjuggernauts

AI products and consulting site (aijuggernauts.com), built with Jekyll on GitHub Pages.

- `index.md`, `healthx.md`, `skillx.md`, `consulting.md`, `contact.md` — main pages
- `ai-news/` + `_data/ai_news.json` — AI News, refreshed daily by `.github/workflows/update-ai-news.yml`
  (AIStudyTools also reads this feed to pick newsletter topics)
- `assets/videos/` — HealthX and SkillX explainer videos

The free teaching tools, simulations and newsletter moved to aistudytools.com, and
Conferences, Faculty Jobs and the Reference Checker moved to theresearchschool.com.
The old URLs under `tools/`, `simulations/`, `newsletter/`, `conferences/` and `jobs/`
are small redirect pages so existing links and shared games keep working.
